# E-Commerce Sales Analytics Project

## 1. Project Introduction
This project focuses on analyzing e-commerce sales data using Python, SQL, and Power BI.

The main purpose is to identify sales trends, evaluate profitability, understand customer purchasing patterns, and support data-driven business decisions.

## 2. Problem Statement
E-commerce businesses generate large amounts of sales data, making it difficult to identify important trends and business opportunities.

This project aims to transform raw sales data into meaningful insights through data analysis and interactive visualizations.

## 3. Project Objectives
- Analyze overall sales and profitability.
- Identify top-performing product categories.
- Evaluate regional sales performance.
- Understand monthly sales trends.
- Identify best-selling products.
- Develop an interactive Power BI dashboard.

## 4. Tools and Technologies
- Python: Data cleaning and exploratory data analysis.
- SQL: Data querying and analysis.
- Power BI: Interactive dashboard development.
- Excel/CSV: Dataset storage.

## 5. Power BI Dashboard
The dashboard provides an overview of important business metrics.

### Key Performance Indicators
- Total Sales: 2.30M
- Total Profit: 286.40K
- Total Orders: Approximately 5K
- Total Customers: 793

### Dashboard Visualizations
- Total Sales by Category
- Total Profit by Region
- Monthly Sales Trends
- Total Sales by Product Name
- Interactive Year and Category Filters

## 6. Business Insights
- Product categories contribute differently to total revenue.
- Regional profitability varies across locations.
- Monthly sales trends show fluctuations throughout the year.
- Product-level analysis helps identify high-performing products.

## 7. Conclusion
This project demonstrates how Python, SQL, and Power BI can be used to analyze e-commerce sales data.

The interactive dashboard helps businesses monitor performance, identify trends, and make informed decisions.
